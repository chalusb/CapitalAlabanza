# Alabanzas — Comunidad Capital

Sitio en HTML, CSS y JavaScript para seleccionar alabanzas y consultar la Biblia.

La Biblia RVR1960 se navega con libro, capítulo y versículo. Muestra el capítulo
completo y permite seguir la lectura con el control remoto.

La narración genera audio bajo demanda con Aura 2 en Cloudflare Workers AI,
con la voz Sirio en español de México. Los audios se reproducen sin guardarse permanentemente.
No se requiere Amazon Polly ni una voz instalada en Fire TV.
